#Meu Primeiro Servidor Back-End

Meu primeiro projeto de servidor back-end desenvolvido com **Node.js** e **Express**.

Tecnologias utilizadas

* Node.js
* Express
* Git
* GitHub

##Projeto

Este projeto foi desenvolvido com o objetivo de praticar os conceitos básicos de desenvolvimento back-end, criação de um servidor HTTP e definição de rotas utilizando Node.js e Express.

##Como executar

Instale as dependências:

```bash
npm install
```

Execute o servidor:

```bash
node servidor.js
```

O servidor será iniciado na porta **3333**.

Acesse no navegador:

```text
http://localhost:3333/oi
```

##O que estou aprendendo

* Criação de servidores com Node.js
* Express
* Rotas HTTP
* Request e Response
* Gerenciamento de dependências com npm
* Git e GitHub
* Versionamento de código
